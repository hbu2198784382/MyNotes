# 函数极限的定义
## 趋于无穷时的极限
对[[函数]] $f:[\alpha,+\infty)\to \mathbf{R}$ ，若存在常数 $a$ 满足 $$\forall~ \varepsilon>0,\exists~X>0,使得~ \forall~x>X, 恒有~ |f(x)-a|<\varepsilon$$ 则称 $a$ 是 $x\to +\infty$ 时的极限，记作 $\displaystyle \lim_{ x \to +\infty } f(x)=a$ 。

若存在常数 $b$ 满足 $$\forall~ \varepsilon>0,\exists~X<0,使得~ \forall~x<X, 恒有~ |f(x)-b|<\varepsilon$$ 则称 $a$ 是 $x\to -\infty$ 时的极限，记作 $\displaystyle \lim_{ x \to -\infty } f(x)=b$ 。

## 趋于有限值的极限
对函数 $f:A\setminus{\{ x_{0} \}}\to \mathbf{R}$ ，若存在常数 $a$ 满足 $$\forall~ \varepsilon >0,\exists~ \delta>0,使得当~ 0<|x-x_{0}|<\delta ~时,恒有~ |f(x)-a|<\varepsilon$$ 则称 $a$ 是 $x\to x_{0}$ 时的极限，记作 $\displaystyle \lim_{ x \to x_{0} } f(x)=a$ 。

## 左极限
对函数 $f:(x_{0}-\alpha,x_{0})\to \mathbf{R}$ （$\alpha>0$） ，若存在常数 $a$ 满足 $$\forall~ \varepsilon >0,\exists~ 0<\delta<\alpha,使得当~ x_{0}-\delta<x<x_{0} ~时,恒有~ |f(x)-a|<\varepsilon$$ 则称 $a$ 是 $x\to x_{0}$ 时的左极限，记作 $\displaystyle \lim_{ x \to x_{0}^- } f(x)=a$ 。

## 右极限
对函数 $f:(x_{0},x_{0}+\beta)\to \mathbf{R}$ （$\beta>0$） ，若存在常数 $a$ 满足 $$\forall~ \varepsilon >0,\exists~ 0<\delta<\beta,使得当~ x_{0}<x<x_{0}+\delta ~时,恒有~ |f(x)-a|<\varepsilon$$ 则称 $a$ 是 $x\to x_{0}$ 时的右极限，记作 $\displaystyle \lim_{ x \to x_{0}^+ } f(x)=a$ 。

> $\displaystyle \lim_{ x \to x_{0} }f(x) = a~\displaystyle \Longleftrightarrow \lim_{ x \to x_{0}^+ }f(x)=\lim_{ x \to x_{0}^- }f(x)=a$ 

## 极限为无穷大
这是**极限不存在**的一种特殊情况，对函数 $f:A\setminus{\{ x_{0} \}}\to \mathbf{R}$ ，若 $$\forall~ M>0,\exists~ \delta>0,使得当~ 0<|x-x_{0}|<\delta ~时,恒有~ |f(x)|>M$$ 则称 $a$ 是 $x\to x_{0}$ 时的极限为无穷大，记作 $\displaystyle \lim_{ x \to x_{0} } f(x)=\infty$ 。

# 数列
数列可以看成一个**定义在正整数集上的[[函数]]** $f:\mathbf{N_{+}}\to \mathbf{R}$ 。对 $n \in \mathbf{N_{+}}$ ，$a_{n}$ 表示其函数值。就记此数列为 $\{ a_{n} \}$ ，$a_{n}$ 称为此数列的通项。

# 数列极限
对数列 $\{ a_{n} \}$ ，若存在一个常数 $a \in \mathbf{R}$ ，$\forall~ \varepsilon > 0,\exists~ N \in \mathbf{N_{+}}$ ，使得 $\forall~ n>N,|a_{n}-a|<\varepsilon$ 恒成立，则称该数列为**收敛数列**，$a$ 就是 $\{ a_{n} \}$ 的极限，记作 $\displaystyle\lim_{ n \to \infty } a_{n} = a$ 。

## 有理运算法则
若 $\displaystyle \lim_{ n \to \infty } a_{n}=a,\lim_{ n \to \infty }b_{n}=b$ ，则有：
1. $\displaystyle \lim_{ n \to \infty } (a_{n}\pm b_{n}) = a+b$ 。
2. $\displaystyle \lim_{ n \to \infty }a_{n}b_{n} = ab$ 。
3. 若 $b\neq 0$ ，则 $\displaystyle\lim_{ n \to \infty }{\frac{a_{n}}{b_{n}}} = {\frac{a}{b}}$ 。

## 其他性质
### 极限的保序性
设 $\displaystyle \lim_{ n \to \infty } a_{n}=a,\lim_{ n \to \infty }b_{n}=b$ ，若 $\exists~ N \in \mathbf{N_{+}}$ 使得 $\forall ~n > N,a_{n}\leq b_{n}$ ，则 $a\leq b$。

### 夹逼定理
设 $\displaystyle \lim_{ n \to \infty } a_{n}=\lim_{ n \to \infty }b_{n}=a$ ，若 $\exists~ N \in \mathbf{N_{+}}$ 使得 $\forall ~n > N,a_{n}\leq c_{n}\leq b_{n}$ ，则 $\displaystyle \lim_{ n \to \infty } = a$。

# 数列的单调性
## 单调递增与单调递减
对数列 $\{ a_{n} \}$ ，若 $\forall~ n \in \mathbf{N+},a_{n}\leq a_{n+1}$ ，则称数列 $\{ a_{n} \}$ **单调递增**，特别地，若 $a_{n}<a_{n+1}$ 恒成立，则称数列 $\{ a_{n} \}$ **严格单调递增**。同理可得数列的单调递减性质。

# 单调有界准则
数列**单调递增且有[[实数#上界|上界]]** $\Longleftrightarrow$ $\displaystyle \lim_{ n \to \infty }=inf~ \{a_{n}\}$
数列**单调递减且有[[实数#下界|下界]]** $\Longleftrightarrow$ $\displaystyle \lim_{ n \to \infty }=sup~ \{a_{n}\}$
# 归并原理
## 子列
设 $\{ a_{n} \}$ 为一个数列，若 $\{ n_{k} \}$ 是一个**严格单调递增**的正整数数列，即
$$n_{1}<n_{2}<\cdots<n_{k}<\cdots ,$$
且 $n_{1}\geq 1$，则按原有顺序取出 $\{ a_{n} \}$ 中的第 $n_{1},n_{2},\cdots,n_{k},\cdots$ 项所构成的数列
$$\{ a_{n_{k}} \}:\quad a_{n_{1}},a_{n_{2}},\cdots,a_{n_{k}},\cdots$$
称为 $\{ a_{n} \}$ 的一个**子列**。

## 归并原理
$\displaystyle \lim_{ n \to \infty } a_{n}=a \Longleftrightarrow \{ a_{n} \}$ 的每一个子列都有极限 $a$ 。

# Cauchy 收敛原理
## Cauchy 数列
若数列 $\{ a_{n} \}$ 满足：$\forall~ \varepsilon > 0,\exists~ N \in \mathbf{N_{+}}$，使得 $\forall~ m,n>N,|a_{m}-a_{n}|<\varepsilon$ 恒成立，则称数列 ${a_{n}}$ 是一个 Cauchy 数列。
## Cauchy 收敛原理
数列 $\{a_{n}\}$ 收敛 $\Longleftrightarrow$ 数列 $\{ a_{n} \}$ 是 Cauchy 数列

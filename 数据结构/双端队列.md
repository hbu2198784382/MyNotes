双端队列（deque）是队列的拓展形式，能够实现从队列的两端对元素进行操作
# 双端队列的实现
双端队列可以使用环形数组与指针实现

```cpp
class Queue{
public:
	int qu[MAX_LEN]; 
	int head = 0,cnt = 0;
	
	bool empty() return (cnt == 0);
	
	void push_front(int n){
		if(cnt == MAX_LEN) return;
		head = (head-1+MAX_LEN)%MAX_LEN;
		qu[head] = n;cnt++;
	}
	
	void push_back(int n){
		if(cnt == MAX_LEN) return;
		qu[(head+cnt)%MAX_LEN] = n;cnt++;
	}
	
	void pop_front(){
		if(empty()) return;
		head = (head+1)%MAX_LEN;
	}
	
	void pop_back(){
		if(empty()) return;
		cnt--;
	}
	
	int front() return(qu[head]);
	int back() return(qu[(head+cnt-1)%MAX_LEN])
}
```

与队列相同，其 PUSH/POP 的时间复杂度均为 $O(1)$ 。

栈（stack）是一种常用的线性数据结构。栈的修改与访问按照后进先出的顺序进行，称为后进先出（last in first out,LIFO）表。

# 栈的实现

一段连续空间加上一个指针就可以实现栈。指针始终指向最后入栈的元素，称为栈顶元素。
```cpp
class Stack{
public:
	int st[MAX_LEN]; 
	int t = 0;
	
	bool empty(){
		return (t == 0);
	}
	
	void push(int n){
		if(t == MAX_LEN) return;
		st[++t] = n;
	}
	
	void pop(){
		if(empty()) return;
		st[t--];
	}
	
	int top() return st[t-1];
}
```

# 栈的操作

## PUSH 入栈

将一个对象压入栈顶，指针指向新元素。入栈的时间复杂度是$O(1)$。
![[stack_push.mp4]]

## POP 出栈

将栈顶元素弹出，指针向下面的元素移动，指向新栈顶。出栈的时间复杂度是$O(1)$。
![[stack_pop.mp4]]

## SEARCH 搜素

在栈中搜素某一元素（是否存在），需要将栈全部遍历一遍，时间复杂度 $O(n)$，空间复杂度 $O(n)$。

```cpp

bool search(Stack st,int target){
	Stack temp;
	int t;
	bool ans = false;
	while(!st.empty()){
		t = st.top();st.pop();
		if(t == target){ans = true;break;}
		temp.push(t);
	}
	while(!temp.empty()){
		st.push(temp.top());temp.pop();
	}
	return ans;
}

```


> [!NOTE] 注意
> 上述操作是包含复原的，如果不需要复原则空间复杂度降低到 $O(1)$。

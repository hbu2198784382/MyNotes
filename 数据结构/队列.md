队列（queue）是一种常用的线性数据结构。栈的修改与访问按照先进先出的顺序进行，称为先进先出（first in first out,FIFO）表。


# 队列的实现

一个环形数组加上两个指针就可以实现队列，一个指针指向队列头，一个指针指向队列位。

```cpp
class Queue{
public:
	int qu[MAX_LEN]; 
	int head = 0,cnt = 0;
	
	bool empty() return (cnt == 0);
	
	void push(int n){
		if(cnt == MAX_LEN) return;
		qu[(head+cnt)%MAX_LEN] = n;cnt++;
	}
	
	void pop(){
		if(empty()) return;
		head = (head+1)%MAX_LEN;
	}
	
	int front() return(qu[head]);
	int back() return(qu[(head+cnt-1)%MAX_LEN])
}
```

# 队列操作

## PUSH 入队

将新元素加入队列尾部，时间复杂度 $O(1)$。

## POP 出队

将头部元素弹出队列，时间复杂度 $O(1)$。

## SEARCH 搜素

搜索队列中某一元素（是否存在），需要将整个队列遍历一遍，时间复杂度 $O(n)$，空间复杂度 $O(1)$

```cpp
bool search(Queue qu,int target){
	int size = qu.tail-qu.head+1,t;
	bool ans = false;
	for(int i=0;i < size;i++){
		t = qu.front();qu.pop();
		if(t == target) ans = true;
		qu.push(t);
	}
}
```

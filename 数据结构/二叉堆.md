# 相关定义
## 完全二叉树
完全二叉树是一种特殊的[[树#二叉树|二叉树]]，除最后一层外，其他层的节点数达到最大，最后一层的节点从左到右连续排列，中间不存在空缺。

### 完全二叉树的存储
完全二叉树有一种简单的存储方式，即使用数组就可以完成。对于一颗完全二叉树：![[Drawing 2026-09-30 11.41.50.excalidraw]]
其对应的序列，就是从上到下，从左到右依次将节点写出：`437526`
不难发现，序列为 $i$ 节点的父节点就是 $\left\lfloor  \frac{i-1}{2}  \right\rfloor~(i\neq 1)$ ，左子节点就是 $2i+1$ ，右子节点就是 $2i+2$，叶子节点是 $\left\lfloor  \frac{n}{2}  \right\rfloor$ 到 $n-1$ ，其中 $n$ 为总节点数。


## 二叉堆
堆（Heap）是一颗完全二叉树，每一个节点都有一个对应值且满足堆性质。分为大根堆与小根堆两种类型。
### 最大堆
对于所有节点，父亲节点的值大于或等于子节点的值。
## 最小堆
对于所有节点，父亲节点的值小于或等于子节点的值。

# 二叉堆的实现
借用完全二叉树的存储方式，用一个数组+指针完成对堆的声明：
```cpp
int heap[MAX],end=-1;
```


# 相关操作
## 获取堆根 ROOT
对于大根堆，最大值就是其堆根；对于小根堆，最小值就是其堆根。时间复杂度 $O(1)$。
```cpp
void root() return heap[0];
```
**基于此特性，二叉堆常常用于需要频繁获取最大值与最小值的场景。** 因为传统数组获取最大值/最小值时间复杂度至少为 $O(n)$。

## 上浮 SWIM
将节点不断与父节点比较，若违反堆性质则交换子节点与父节点。
```cpp
void swim(i){
	int temp;
	while(i>0){
		if(heap[(i-1)/2]>=heap[i]) break; // or <=
		temp=heap[(i-1)/2];heap[(i-1)/2]=heap[i];heap[i]=temp; // swap
		i = (i-1)/2;
	}
}
```
时间复杂度：$O(\log n)$

## 下沉 SINK
将节点不断与子节点比较，若违反堆性质则交换子节点与父节点。
```cpp
void sink(i){
	int s,temp;
	while(1){
		s = i;
		if(2*i+1 <= end and heap[2*i+1] < heap[s]) s = 2*i+1;
		if(2*i+2 <= end and heap[2*i+2] < heap[s]) s = 2*i+2;
		if(s == i) break;
		temp = heap[s];heap[s] = heap[i];heap[i] = temp;
		i = s;
	}
}
```
时间复杂度：$O(\log n)$

## 入堆 PUSH
1. 将新元素加入数组尾端
2. 新节点上浮
```cpp
void push(x){
	heap[++end] = x;
	swin(end);
}
```

## 弹出堆顶 POP
1. 将最后一个节点移动到堆顶
2. 堆顶下沉
```cpp
void pop(){
	heap[0] = heap[end--];
	sink(0);
}
```

## 建堆 BUILD HEAP
### 自顶向下法
每次使用 INSERT 依次将元素放入堆中后上浮，算法复杂度 $O(n\log n)$。适用于不知道具体元素个数的情况。
### 自底向上法（heapify）
从最后一个非叶节点（$\left\lfloor  \frac{n}{2}  \right\rfloor-1$）开始，依次向前对每个节点下沉，算法复杂度 $O(n)$ 。
> [!NOTE] 正确性证明
> 在处理 $i$ 节点时，其左右子树一定被处理过，故左右子树均是合法堆。$i$ 节点下沉后，新 $i$ 节点为根的树成为合法堆。

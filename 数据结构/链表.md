链表（List）是一种利用节点存储数据的数据结构，特点是**插入与删除的高效性**

# 链表的实现

使用节点与指针就可以实现链表

```cpp
class ListNode{
	public:
	int val;
	ListNode* next;
}

// build a list
ListNode* rootptr = new Listnode;
ListNode* temp = rootptr;

for(int i=0;i < LISTSIZE;i++){
	temp -> val = i;
	ListNode* newnode = new Listnode;
	temp -> next = newnode;
	temp = newnode;
}
```

# 链表操作

## INSERT 插入

链表的插入非常高效，时间复杂度 $O(1)$ 。

```cpp
void insert(ListNode* front, ListNode* newnode){
	newnode -> next = front -> next;
	front -> next = newnode;
}
```

## DELETE 删除

链表的删除也非常高效，时间复杂度 $O(1)$ 。（将下一个节点的属性完全复制到当前节点中即可）

```cpp
void delete(ListNode* target){
	target -> val = (target -> next) -> val;
	target -> next = (target -> next) -> next;
}
```


> [!NOTE] 注意
> 这种删除方式无法删除尾节点。如果要删除尾节点，必须找到其前驱节点。对于单向链表，寻找前驱节点的复杂度为 $O(n)$。


# 双向链表

给链表加上前驱节点指针，就成为了双向链表

```cpp
class ListNode{
	public:
	int val;
	ListNode* next;
}

// build a list
ListNode* rootptr = new Listnode;
ListNode* temp = rootptr;

for(int i=0;i < LISTSIZE;i++){
	temp -> val = i;
	ListNode* newnode = new Listnode;
	temp -> next = newnode;
	temp = newnode;
}
```

使用双向链表，可以将寻找前驱节点的时间复杂度化为 $O(1)$。

# 链表与数组的对比

| 操作  | 数组     | 链表     |
| --- | ------ | ------ |
| 索引  | $O(1)$ | $O(n)$ |
| 插入  | $O(n)$ | $O(1)$ |
| 删除  | $O(n)$ | $O(1)$ |
# 不使用结构体的链表
用两个数组实现：`val[n]` 用于存放节点的值，`next[n]` 用于存放后继节点的索引：
```cpp
vector<int> val,nxt;

// build a list
val.resize(n);nxt.resize(n);
for(int i=0;i < n;i++){scanf("%d",&val[i]);nxt[i]=i+1;}nxt[n-1]=-1;

// create a new node
void insert_node(int node,int newval){
    val.push_back(newval);
    nxt.push_back(nxt[node]);
    nxt[node] = nxt.size()-1;
}

void delete_node(int node){
    val[node]=val[nxt[node]];
    nxt[node]=nxt[nxt[node]];
}

void range(int idx){
    while(idx >= 0){printf("%d\n",val[idx]);idx=nxt[idx];}
}
```


> [!NOTE] 思考
> 对于若个元素处于互不相交的集合中，如何判断两个元素是否属于同一个集合？

并查集（Union-Find,DSU）是一种用于判断、管理元素所属集合（互不相交）的数据结构。基于[[树]]完成数据的存储与操作。
# 核心思想
并查集的核心思想是：**用一棵树表示一个集合**。每个节点都是一个元素，树的根节点表示这个集合的**代表元**，只要两个元素的代表元相同，说明两个元素在同一个集合内。

# 并查集的实现

用一个[[树]]就可以实现 DSU，在这里使用额外的 `size` 属性记录每一棵树的节点数量：
```cpp
int parent[MAXN],size[MAXN];
memset(parent,-1,sizeof(int)*MAXN);
memset(size,1,sizeof(int)*MAXN);
```

# 相关操作
## 查找 FIND
FIND 操作可以查找出某一元素所在集合的代表元素（树根节点）。
使用递归完成，并利用路径压缩的做法，即在搜索的过程中，将当前点之间挂在根节点下方。下一次搜索时就可以一步找到根。时间复杂度接近 $O(1)$ 。（实际上的复杂度是 $O(\alpha(n))$ ，其中 $\alpha(n)$ 是反阿克曼函数，增长速度极慢接近常数。）
```cpp
int find(int x){
	if(parent[x] == -1) return x;
	parent[x] = find(parent[x]);
	return parent[x];
}
```

## 合并 UNION
UNION 操作可以将两个元素
每一次合并时，如果**总是将较小的树挂到较大的树下**，就可以使得树高变得更小，加快查找速度。时间复杂度同上接近 $O(1)$ 。
```cpp
void union(int a,int b){
	int rootA = find(a),rootB = find(b),temp;
	if(rootA == rootB) return;
	if(size[rootA] > size[rootB]){temp=rootA;rootA=rootB;rootB=temp;}
	parent[rootA] = rootB;
	size[rootB] += size[rootA];
}
```

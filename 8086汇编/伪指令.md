伪指令是由编译器执行的指令，在编译过程中根据伪指令进行相关编译工作。

# segment 与 ends

用于定义一个段，segment 说明一个段的开始，end 说明一个段的结束。
```asm
段名 segment
汇编指令...
段名 ends
```

# end

用于标记程序的结束位置，同时标记程序的入口（使用标号）
格式为 `end s`，编译器将程序入口（CS:IP）指向s。

# assume

将某一个[[段寄存器]]与相关段进行关联。

```asm
assume cs:codeseg ; 将cs与codeseg关联

codeseg segment

...

codeseg ends
end
```


> [!warning] 注意
> assume 指令并无法将段寄存器自动指向某个段，仅仅起到声明作用。在程序开始后，需要将地址手动存入段寄存器中。同时存储过程需要转存（参考[[段寄存器#其他段寄存器]]）

# 标号

标记一个地址，格式为`标号名称:汇编指令`


进行连续数据的传输操作

# MOVSB指令

利用[[标志寄存器#DF 标志|DF标志]]，执行`movsb`相当于

```mermaid
graph LR
    A[将DS:SI存入ES:DI] --> B[若df=0，则si++,di++]
    A --> C[若df=1，则si--,di--]
```

# MOVSW 指令

利用[[标志寄存器#DF 标志|DF标志]]，执行`movsb`相当于

```mermaid
graph LR
    A[将DS:SI存入ES:DI] --> B[若df=0，则si+=2,di+=2]
    A --> C[若df=1，则si-=2,di-=2]
```

# REP 指令

一般与`movsb/movsw`指令复合使用
```asm
rep movsb

;等价于
s:movsb
loop s

rep movsw;同理

```

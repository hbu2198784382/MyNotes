# 数据类型

**字节（byte）**：用8字节[[寄存器]]来存储一个字节。一个内存单元存放一个字节。

**字（word）**：用16字节[[寄存器]]来存储一个字。一个字 = 两个字节
一个内存单元存放一个字节，因此在内存中存放一个字需要两个连续的内存单元。

# DS 与 \[address\]

DS 与 \[address] 的配合[[寄存器#MOV 指令|MOV指令]]使用，可以从内存中存取数据。**特别地，偏移地址可以是\[bx]，甚至是\[bx+idata]，也能是\[si+idata]、\[di+idata]** （参考 [[寄存器#SI 与 DI]]）。约定用idata表示一个常量。

| 指令               | 作用                    |
| ---------------- | --------------------- |
| `mov al,[idata]` | 将ds:\[idata]中的内容复制到al |
| `mov [idata],al` | 将al中的内容读取到ds:\[idata] |

> [!NOTE] 传输数据类型
> 在没有进行特别声明的情况下，一次mov指令传输的数据类型取决于**目标寄存器的大小**。如果目标寄存器是8字节，则取当前内存单元的数据。如果目标寄存器是16字节，则取 `ds:[address]` 为低位字节，`ds:[address+1]` 为高位字节送入寄存器。

# 段前缀

使用\[address]，进行内存访问时，也可以使用其他段寄存器。此时显式的声明寄存器即可。
如`mov ax,ss:[idata]`, `mov ax,ds:[idata]`, `mov ax,es:[idata]`。


# 传输数据类型指定

使用 `ptr` 操作符指定访问内存的长度

```asm
;访问字型数据
mov word ptr ds:[0],1
inc word ptr [bx]
add word ptr [bx],2

;访问字节型数据
mov byte ptr ds:[0],1
inc byte ptr [bx]
add byte ptr [bx],2
```


> [!NOTE] 注意
> `push` 指令和 `pop` 指令默认访问字型数据。

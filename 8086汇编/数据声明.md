# DW 指令

使用dw指令在内存中创建字型数据。
```asm
dw 0123h,0456h,0789h ; 创建了三个字型数据
```

# DB 指令

使用dw指令在内存中创建字节数据。

```asm
db 'Hello World!' ; 创建了12字节的字节型数据，用ASCII码存储在内存中
```

# DD 指令
使用dd指令在内存中创建双字（dword）型数据（32bit）
```asm
dd 1 ; 创建了双字型数据00000001H
```


# DUP 操作符
使用dup创建重复的数据
```asm
db 3 dup (0) ; 等价于db 0,0,0
db 3 dup (1,2) ; 等价于db 1,2,1,2,1,2
db 2 dup ('abc','ABC') ; 等价于db 'abcABCabcABC'
```

# 使用多个段进行数据管理

我们可以在程序中定义多个段，防止内存空间出现冲突。
```asm
assume cs:code,ds:data,ss:stack ; 将段寄存器指向这一段的开头地址

data segment
	... ; 创建存储数据的专用段
data ends

stack segment
	... ; 创建栈操作的专用段
stack ends

code segment
	start:  mov ax,stack ; 程序入口
			mov ss,ax
			mov sp,0  ; 栈顶初始化
			
			mov ax,data
			mov ds,as ; 数据段初始化
			
			...
			
code ends
end start ; 标记开始位置
```

关于 cs，ds，ss 手动指向，参考[[伪指令#assume]]

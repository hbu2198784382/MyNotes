# 栈机制

8086CPU可以将一段内存当作[[栈]]进行操作，并提供了相关指令进行管理。
**一般需要暂存数据时，都使用栈来实现。**

# SS 与 SP
SS与SP都和栈操作有关，**任意时刻，SS:SP都指向栈顶内存单元**。

## PUSH 指令

```mermaid
flowchart TD
	step0[" 开始运行指令：push ax"]
    step1[" SP = SP - 2，SS:SP 指向当前栈顶前面的单元，以当前栈顶前面的单元为新的栈顶"]
    step2[" 将 AX 中的内容送入 SS:SP 指向的内存单元处，SS:SP 此时指向新栈顶"]
    step0 --> step1 --> step2
```

## POP 指令
```mermaid
flowchart TD
	step0[" 开始运行指令：pop ax"]
    step2[" SP = SP + 2，SS:SP 指向当前栈顶下面的单元，以当前栈顶下面的单元为新的栈顶"]
    step1[" 将 SS:SP 指向的内存单元处的内容送入 AX"]
    step0 --> step1 --> step2
```

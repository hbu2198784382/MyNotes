# 通用寄存器

8086CPU有四个通用寄存器：AX、BX、CX、DX，这四个寄存器都是16位的（2字节）
其中，AX的低八位可以分为AL，高八为可以分为AH。同理，有BL、BH、CL、CH、DL、DH。

# MOV 指令

| 指令           | 作用              |
| ------------ | --------------- |
| `mov ax,114` | 将立即数114复制进寄存器ax |
| `mov al,ah`  | 将ah的内容复制到al     |

## SI 与 DI

si 与 di 拥有和 bx 相似的功能，可以使用\[si+idata]，\[di+idata]
特别地，si 与 di 结合 bx 可以更加灵活地寻址。

以下的代码都是合法的：
```asm
mov ax,[bx+si]
mov ax,[bx+di]

mov ax,[bx+si+idata]
mov ax,[bx+di+idata]
```

## BP 寄存器

以下代码都是合法的：
```asm
mov ax,[bp] ;默认以ss为段寄存器
mov ax,[bp+idata]

mov ax,[bp+si]
mov ax,[bp+di]

mov ax,[bp+si+idata]
mov ax,[bp+di+idata]

```

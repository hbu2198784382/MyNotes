# 高精度加法（不考虑负数）

```Cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	string a,b;
	getline(cin,a);getline(cin,b);
	stack<int> res;
	int c=0;
	int i=a.size()-1, j=b.size()-1;
	
	while (i>=0||j>=0||c){
		int sum=c;
		if(i>=0)sum+=a[i--]-'0';
		if(j>=0)sum+=b[j--]-'0';
		res.push(sum%10);
		c = sum/10;
	} 
	while(!res.empty()){
		cout << res.top();
		res.pop();
	}
	return 0;
}
```

## 解析：

1. 传入参数a、b，创建栈res用于存储结果，创建变量i，j分别作为a，b的指针，创建c用于存储进位。
2. i，j初始化为size()-1，从两个数字的低位向高位移动。
3. **循环条件判断（核心）**：只要a，b任意一个没有索引完成，或者进位不为0，继续向res入栈。
4. `a[i--]-'0'` 其实做了三件事：先取出当前指针指向位的数字加入sum，再把取出来的字符转化为数字==（小技巧：'9' - '0' 的ascii码运算）== ，最后指针向前移一位。
5. 将当前sum推入res栈 ，sum的十位存入c作为下一次运算的进位。
6. 最后将res反转（因为res是逆序存储），栈顶依次弹出到空。

# 高精度加法（基于递归的精简版）

```cpp
string add(string a,string b,int carry){
    if(a == "" && b == "" && carry == 0) return "";
    if(a == "") a = "0";if(b == "") b = "0";
    int res = carry + (a[0]-'0') + (b[0]-'0');
    return(to_string(res%10) + add(a.substr(1),b.substr(1),res/10));
}
```

**注意：输入数据与返回数据都是倒序的**

# 高精度乘法

```Cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	string a,b;
	getline(cin,a);getline(cin,b);
	int n=a.size(),m=b.size();
	
	if(a=="0"||b=="0"){
		cout<<0;return 0;
	}
	vector<int> res(n+m,0);
	
	for(int i=0;i<n;i++){
		for(int j=0;j<m;j++){
			res[i+j] += (a[i]-'0')*(b[j]-'0');
		}
	} 
	
	for(int i=n+m-1;i>0;i--){
		if(res[i]>=10){
			res[i-1]+=res[i]/10;
			res[i]%=10;
		}
	}
	
	for(int i=0;i<=n+m-2;i++){
		if(i==0&&res[0]==0) continue;
		cout<<res[i];
	}
	
	return 0;
}

```


# 高精度乘法（精简版）

```cpp
string mul(string rev_a,string rev_b){
    if(rev_a == "0" || rev_b == "0") return "0";
    int* temp = new int [rev_a.size()+rev_b.size()]();
    for(int i = 0;i <= rev_a.size()-1;i++){
        for(int j = 0;j <= rev_b.size()-1;j++){
            temp[i+j] += (rev_a[i] - '0') * (rev_b[j] - '0');
        }
    }
    string ans = "";
    for(int i = 0;i <= rev_a.size()+rev_b.size()-2;i++){
        temp[i+1] += temp[i] / 10;
        temp[i] %= 10;
        ans += temp[i] + '0';
    }
    if(temp[rev_a.size()+rev_b.size()-1] != 0) ans += \temp[rev_a.size()+rev_b.size()-1] + '0';
    return ans;
}
```

**注意：输入数据与返回数据都是倒序的**

# 压位提速
## 原理

在传统的列竖式计算中，我们使用每一位分别计算。但是对于计算机，一位数求和与多位数求和并无太大区别。因此在高精度算法中，可以将**多位压为一位进行计算**。

## 加法

```cpp
#include <bits/stdc++.h>
using namespace std;
int BASE = 1000000000;
int WIDTH = 9;

string add(string a, string b){
    queue<int> qa,qb;
    stack<int> ans;
    int i,j,carry = 0;
    for(i = a.size() - 1;i >= WIDTH - 1; i-= WIDTH){
        qa.push(stoi(a.substr(i-WIDTH+1,WIDTH)));
    }if(i >= 0) qa.push(stoi(a.substr(0,i+1)));
    for(j = b.size() - 1;j >= WIDTH - 1; j-= WIDTH){
        qb.push(stoi(b.substr(j-WIDTH+1,WIDTH)));
    }if(j >= 0) qb.push(stoi(b.substr(0,j+1)));
    while (!qa.empty()||!qb.empty()||carry){
        int res = carry;
        if(!qa.empty()){res += qa.front();qa.pop();}
        if(!qb.empty()){res += qb.front();qb.pop();}
        ans.push(res%BASE);carry = res/BASE;
    }
    string r = "";
    if (!ans.empty()) {
        r = to_string(ans.top());
        ans.pop();
    }
    while (!ans.empty()){
        string temp = to_string(ans.top());
        ans.pop();
        if (temp.size() < WIDTH) temp.insert(0, WIDTH - temp.size(), '0');
        r += temp;
    }
    return r;
}
```


> [!NOTE] BASE与WIDTH的选值
> 因为int的最大值2147483647在$10^{9}$与$10^{10}$之间，选取BASE选择1e9可以在int范围内最大程度划分


# 高精度减法

```cpp
string sminus(string a_rev,string b_rev,int c){
    // assume a >= b
    if(a_rev == "" && b_rev == "" && c == 0) return "";
    if(a_rev == "") a_rev = "0";
    if(b_rev == "") b_rev = "0";
    int cn = 0,temp = a_rev[0]-'0';
    if(temp < c){temp+=10;cn++;}
    temp-=c;
    if(temp < b_rev[0]-'0'){temp+=10;cn++;}
    temp-=b_rev[0]-'0';
    string ans = to_string(temp) + sminus(a_rev.substr(1),b_rev.substr(1),cn);
    return ans;
}
```

**注意：此算法假设a<b恒成立，同时a，b与结果均逆序存储。**

# 高精度浮点数

采用科学计数法 $a \times 10^{-k}$ 的形式表示一个高精度小数。可以定义以下结构：
```cpp
struct hfl{
	string a;
	int k;
}
```
**为了简便，还是让a倒序存储。**

## 浮点数加法

将指数对齐，调用之前的高精度加法，即可实现高精度浮点数的加法：
```cpp
hfl add_hfl(hfl a,hfl b){
	int e = a.k-b.k;
	hfl ans;
	if(e > 0){
		string temp = "";
		for(int i=1;i < e;i++) temp += "0";
		temp += b;
		ans.a = add(temp,a.a,0);
		ans.k = a.k;
	}else if(e < 0){
		string temp = "";
		for(int i=1;i < -e;i++) temp += "0";
		temp += a;
		ans.a = add(temp,b.a,0);
		ans.k = b.k;
	}else{
		ans.a = add(a.a,b.b,0);
		ans.k = a.k; // or b.k
	}
	return ans;
}
```

## 浮点数乘法

将指数相加，底数部分相乘即可，假设保留m位数字
```cpp
hfl mul_hfl(hfl a,hfl b,int m){
```

# 牛顿迭代法

牛顿迭代法可以用于求取方程的根，推导过程参考[牛顿迭代法](https://www.bilibili.com/video/BV1zwZEYqE3s)

求解 $f(x)=0$ 时，先取 $x_{1}$ 为一个近似解，再利用递推式
$$x_{n+1}=x_{n}-\frac{f(x_{n})}{f'(x_{n})}$$
当 $n$ 越大，$x_{n}$ 越接近真实根。

## 误差分析

设第 $n$ 次求解的误差 $e_{n}=|r-x_{n}|$，其中 $r$ 是实际根。
若要精确到小数点第 $k$ 位，则 $e_{n}<10^{-k}$

因此只要求最小的 $n$，使得 $e_{n}<10^{-k}$ 成立。


> [!NOTE] 平方收敛性质
> 事实上，牛顿迭代法具有平方收敛性质，即每次迭代，正确的位数翻倍。因此，精确到小数点后 $n$ 位，只需要计算 $\log_{2}n$ 次即可。（循环条件为 $2^i\leq n$）即可。

## 获取第一个近似根

# 高精度除法

因为 $a \times b = a \times \frac{1}{b}$ ，故求高精度除法等价于求一个数的倒数（a,b都是整数）。


当 $x\leq {10}$，采用试根：从 $0.1,0.2,\dots,0.9$ 任取数字，找出与x相乘等于1的数。
当 $x>10$，$\frac{1}{x}<0.1$ 必然成立，即第一位小数必然是0，故令 $x_{1}=0.01$，开始牛顿迭代。

由于 $\frac{1}{x}=m$ 的根即为 $m$ 的倒数，故令 $f(x)=\frac{1}{x}-m$， 牛顿迭代公式为$$x_{n+1}=x_{n}(2-mx_{n})$$由于第一位小数准确，只需要迭代 $\log_{2}k$ 次就可以保留 $k$ 位小数。

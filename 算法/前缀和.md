
前缀和是一种技巧，用于快速求解一个区间的和

# 一维前缀和

> [!NOTE] 例题
> 求一个数组第 $l$ 项到第 $r$ 项的和

分析易得，计算的时间复杂度是 $O(n)$，此过程无法化简。

如果需要反复多次计算不同区间的和，那么就可以借助[[递归与动态规划#动态规划|动态规划]]的思想，仅需第一次计算时间复杂度为 $O(n)$，后面每次查询时间复杂度均为 $O(1)$。

首先考虑前 $k$ 项和 $S_{k}$ ，有递推关系式（$k>1$ 时）：$$S_{k}=S_{k-1}+a_{k}$$
特别地，当 $k=1$ 时，$S_{1}=a_{1}$。
那么，计算从第 $l$ 项到第 $r$ 项的和，就转化为了 $S_{r}-S_{l-1}$ （注意数组下标转换）
综上，优化代码为：

```cpp

int* table = int new [n];

void build_table(){
	int sum = 0;
	for(int i=0;i<n;i++){
		sum += arr[i];
		table[i] = sum;
	}
} 

int query(int l,int r){
	return table[r+1]-table[l];
}

```

# 二维前缀和

> [!NOTE] 例题
> 求一个矩阵的任意子矩阵的所有元素和

假设 $S_{i,j}$ 为第 $0$ 到 $i-1$ 行，第 $0$ 到 $j-1$ 列的所有元素和，利用容斥原理，得到递推关系式$$S_{i,j}=a_{i,j}+S_{i-1,j}+S_{i,j-1}-S_{i-1,j-1}$$
因此，得到左上角 $(i_{1},j_{1})$ ，右下角 $(i_{2},j_{2})$ 对应子矩阵的元素和就是$$S_{i_{2},j_{2}}-S_{i_{1}-1,j_{2}}-S_{i_{2},j_{1}-1}+S_{i_{1}-1,j_{1}-1}$$

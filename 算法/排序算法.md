# 冒泡排序

冒泡排序是所有排序算法中最基础最简单的算法。算法时间复杂度 $O(n^2)$。

其基本的思路是将输入的数组从前往后依次扫描，依次两两对比，如果前者大于后者则交换顺序，直到排序完成。

```cpp
void BubbleSort(int* arr,int n){
	bool flag = false;
	while(!flag){
		flag = true;
		for(int i=0;i <= n-2;i++){
			if(a[i]>a[i+1]){
				flag = false;
				// swap
				int t = a[i];
				a[i] = a[i+1];
				a[i+1] = t; 
			}
		}
	}
}
```

# 计数排序

创建一个长度为（数组最大值+1）的长度数组，统计每个数的出现次数，从小到大依次输出即可。算法的时间复杂度为 $O(n+m)$ ，空间复杂度为 $O(m)$ ，其中 $m$ 表示数组中的最大数。

```cpp
void CountingSort(int* arr,int n){
	int m = max(arr);
	int* temp = new int [m+1]();
	for(int i = 0;i < n;i++) temp[arr[i]]++;
	for(int i = 0;i <= m;i++){
		for(int j = 0;j < temp[i];j++) cout<<j;
	}
}
```

计数排序拥有接近线性的时间复杂度，但是却造成了巨大的空间浪费。如果存在极端数据，可能导致算法性能大幅度下降。如何解决这一问题？参考基数排序。

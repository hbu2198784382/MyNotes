# 递归的一般思路

递归即函数调用自身，将问题划分为更小的子问题，再加以相关的边界条件进行限制。
总结为三个要素：**自调用、子问题划分（分治）、边界条件**。

## 递归的使用例子：递归排序

> [!NOTE] 例题
> 给一个无序的数组，按从小到大的顺序排序。利用递归**分治**的思想，可以把一个数组分为左右两个小数组进行划分。

假设 `sort(arr)` 函数能够把输入的数组 `arr` 排序，那么把左右两个小数组使用 `sort` 函数进行排序以后，使用双指针从前往后比较两个有序数组各数大小即可排序完成。那么这个将数组进行排序的函数就是 `sort` 本身，也就是说 `sort` 在自己的函数体中进行了**自调用**。

如此下去，`sort` 函数会进入死循环，那么需要**边界条件**来结束递归：当数组被划分到仅剩下一个数的时候，就不需要再比较了，返回当前数就可。

综上，可以有以下 c++ 代码：（用 string 避免数组指针操作，数字限制在一位数）

```Cpp
#include <bits/stdc++.h> 
using namespace std;

string sort(string arr){
	if(arr.size() <= 1) return(arr);//border
	else{
		int t = arr.size() / 2;
		string left = sort(arr.substr(0,t));
		string right = sort(arr.substr(t,arr.size() - t));
		int i = 0,j = 0;
		string res = "";
		while(i < left.size() || j < right.size()){
			if(i < left.size() && j < right.size()){
				if(left[i] < right[j]) res += left[i++];
				else res += right[j++];
			}
			else if(i < left.size() && j >= right.size()) res += left[i++];
			else res += right[j++]; 
		}
		return res;
	}
}
```

## 递归算法的复杂度分析

以递归排序为例，假设函数 $f(n)$ 表示n长度字符串的排序时间，则满足关系式（近似）

当$n \neq 1$时，


$$
f(n) = 2f\left( \frac{n}{2} \right) +n 
$$
当$n = 1$时，$f(n) = 1$

递推得到$f(n)=n + n \log_{2}n$
因此复杂度$O(n\log n)$

# 递归树

递归的自调用过程中，将一个问题划分为了多个子问题。这些问题之间就形成了一颗[[树]]的结构。这棵树称为递归树。

## 自顶向下法

从递归树的根节点开始，依次向下解决问题的方法，成为自顶向下法。自顶向下在递归的过程中，需要哪一个子问题的数据，就立即计算需要的数据。

## 自底向上法

从递归树的所有叶节点开始，依次向上合并所有子问题，最终得到根节点问题的答案。**一般使用自底向上法写的程序不需要递归调用，更加简洁。**

# 动态规划

再递归的过程中，往往面临着非常多的子问题，常常导致函数拥有极高的时间复杂度。
经过分析，有很大一部分的时间占用是因为计算了**重复的子问题**。

**因此，我们牺牲空间效率换取时间效率，用一张动态的表格dp存储已经计算的子问题答案，在调用之前先查表，如果没有数据就进行计算，再存入表内。**

## 动态规划的使用例子：斐波那契数列

例如对斐波那契数列的计算过程中，不优化的代码如下：

```cpp
#include <bits/stdc++.h>
using namespace std;

int fib(int n){
	if(n == 1 || n == 2)return 1;
	else return(fib(n-1) + fib(n-2));
}

int main(){
	int n;
	cin >> n;
	cout << fib(n);
	return 0;
}
```

分析得到算法时间复杂度为 $O(F_{n})$ 其中 $F_{n}$ 为斐波那契数列前n项，空间复杂度 $O(1)$。

优化以后：
```cpp
#include <bits/stdc++.h>
using namespace std;

int fib(int* dp, int n){
	if(dp[n]>0)return dp[n];
	else {
		int res = fib(dp,n-1) + fib(dp,n-2);
		dp[n] = res;
		return res;
	}
}

int main(){
	int n;
	cin >> n;
	int* dp = new int [n+2]();
	dp[1] = 1;dp[2] = 1;
	cout << fib(dp,n);
	return 0;
}
```

分析得到算法时间复杂度为 $O(n)$ ，空间复杂度 $O(n)$。

## 状态转移方程

状态转移方程是用于描述解数递归关系的方程（组），**是利用动态规划解决问题的核心**。动态规划过程中，可以将一个状态方程转化为一个表格看待。


# 0-1 背包问题

> [!NOTE] 例题
>假设有 $n$ 个物品和一个容量为 $W$ 的背包，第 $i$ 个物品的重量为 $w_{i}$，价值为 $v_{i}$ 。选择物品使得背包中的物品总价值最大且背包中物品总重量不超过背包容量，求最大总价值。

假设从1到 $n$ 依次选择，选到第 $i$ 个物品时，且背包容量为 $w$ 时的最大价值为 $f(i,w)$

在选择第 $i$ 个物品时，我们有两种选择：**选 或 不选**
如果选择第 $i$ 个物品，前提是保证 $w \geq w_{i}$ ，则剩下 $w-w_{i}$ 的空间给前面的 $i-1$ 个物品。因此只要前 $i-1$ 个物品价值最大即可。
如果不选择第 $i$ 个物品（空间够但是不选，或者空间不够），则将所有空间 $w$ 都预留给前面的 $i-1$ 个物品。

那么有 ( $w \geq w_{i}$ 时 )$$f(i,w) = max(f(i-1,w),f(i-1,w-w_{i})+v_{i})$$
若 $w < w_{i}$ ，则 $f(i,w)=f(i-1,w)$

**边界条件：如果空间为0，则总价值为0，即 $f(i,0)=0$**
此时发现，时间复杂度 $O(nW)$，空间复杂度为 $O(nW)$，是否可以进一步优化？

## 数组打平

在建dp表的过程中（以i为行，以w为列），第k行的内容完全取决于第k-1行的内容，因此，表格从上到下填写。这样看来，我们只需要**两个一维数组交替使用**。还可以进一步优化吗？

如果只使用一个一维数组（i从左到右递增），由于在计算 $f(i-1,w-w_{i})$ 的过程中，需要左侧的数据，**因此我们从右往左遍历**，这样就可以保证左侧数据保留了上一行计算的内容，而不再计算过程中被覆盖导致错误。空间复杂度被优化到 $O(W)$

最终得到核心代码（自底向上）：
```cpp
int *dp = new int [W+1];
for(int i=0;i<=W;i++) dp[i] = -1; // initialize
dp[0] = 0; // border

// dp
for(int i=0;i<n;i++) for(int j=W;j>=w[i];j--) dp[j] = max(dp[j],dp[j-w[i]]+v[i]);
```

# 多重背包问题

> [!NOTE] 例题
>假设有 $n$ 种物品和一个容量为 $W$ 的背包，第 $i$ 个物品的重量为 $w_{i}$，价值为 $v_{i}$，共有 $k_{i}$ 个。选择物品使得背包中的物品总价值最大且背包中物品总重量不超过背包容量，求最大总价值。

参考0-1背包问题，该题也可以用相似的思路完成。假设选取前 $i$ 个物品时，背包空间为 $w$ 时，最大的总价值为 $f(i,w)$，则有$$f(i,w)=max_{k=0}^{k_{i}}(f(i-1,w-kw_{i})+kv_{i})$$
但是此方法的时间复杂度达到$O\left( W\sum_{i=1}^n k_{i}\right)$，现在思考优化方式

## 二进制分组优化

注意到在对每一类物品进行选取时，将所有可能的数量都遍历了一遍。先计算$f(i-1,w)$，再计算$f(i-1,w-w_{i})$，依次计算$f(i-1,w-2w_{i})$、$f(i-1,w-3w_{i})$、...、$f(i-1,w-kw_{i})$。

如果把每一类的每一个物品都编上号，视为不同的物体，只是属性相同。**那么这个问题就与0-1背包问题同构。** 但是在同类物品的决策过程中消耗了大量时间。

为了减小此过程耗时，利用二进制进行划分。取上限 $m \in \mathbb{N}$ 使得 $2^m\leq k_{i}<2^{m+1}$。（即$m=\lfloor \log_{2}k_{i} \rfloor$ )，假设将每组相同的物品划分成1、2、4、8、...、m的组合，发现恰好有$$1+2+4+\dots+m=k_{i}$$
因此将物品捆绑，减少遍历次数。时间复杂度化简为 $O\left( W \sum_{i=1}^n\log_{2}k_{i} \right)$


# 区间 DP

> [!NOTE] 例题
> 假设给出 $n$ 堆石子，第 $i$ 堆石子的重量为 $w_{i}$ ，现在每次操作可以将相邻的两堆石子合并，每次合并的代价即为两堆石子的重量和。求将所有石子合成一堆的最小总代价。

假设从第 $i$ 堆石子到第 $j$ 堆（$j\geq i$）石子全部合并为一堆的最小总代价为 $f(i,j)$，那么利用分治的思想，列出状态转移方程：$$f(i,j)=min_{k=i}^j(f(i,k)+f(k,j)+c)$$
其中c是此次合并的代价。

特别地，当 $i=j$ 时，$f(i,j)=0$ （即不做合并）

dp计算 $f(1,n)$ 即为答案。


> [!NOTE] 拓展
> 如果石子围成一个环，应该如何处理？

将链延长两倍，变成 $2n$ 堆，其中第 $i+n$ 堆与第 $i$ 堆是相同的。计算$f(1,n)$，$f(2,n+1)$，$f(3,n+2)$，... ，$f(n,2n-1)$ 中的最小值即为答案。

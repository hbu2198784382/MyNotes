# 存边

直接将图的所有边存在数组中。每条边都包含一个起点和一个终点，[[图论相关概念#赋权图|带权边]]还包含权。
这种方法的遍历效率低下，一般不用于遍历图。

```cpp
struct Edge{
	int u,v,weight;
}

vector<Edge> e;
```

# 邻接矩阵

使用一个二维数组存边，其中 `adj[u][v]` 为1表示存在从u到v的边，为0表示不存在。带权边即用权表示。
这种方法只能**表示没有重边的图**，显著的优势是可以高效率查询一条边，但是空间浪费可能会很大。

```cpp
vector<vector<bool>> adj; // 不带权
vector<vector<int>> adj; // 带权
```

# 邻接表
使用数组与[[链表]]实现，其中 `head[n]` 存放各节点的指针，链表用于存放边，其属性有 `to` 与 `next` （可能还有 `w` 表示权）。其中 `id` 表示边的编号，`to` 表示指向的下一个节点，`next` 表示下一条边（同一起点的边）的地址。
这种方法可以表示任意的图，但是内存占用依然很大。
```cpp
struct Edge {
	int w;
	int to;
	Edge* next;
}
Node* head[n];
```

# 链式前向星
是对邻接表的改进，使用头插法化简代码：(假设 $n$ 个节点，$m$ 条边的有向赋权图)

```cpp
// initialize
int head[n],nxt[m],w[m],to[m],cnt=-1;
memset(head,-1,sizeof(head)); // -1 represents NULL

void link(int u,int v,int ww){ // link node u to v
	nxt[++cnt] = head[u];
	head[u] = cnt; // insert headnode
	w[cnt] = ww;
	to[cnt] = v;
}
```

查询 $u$ 到 $v$ 的某边的时间复杂度 $\Leftrightarrow$ 遍历 $u$ 的所有出边的时间复杂度 $\Leftrightarrow$ $O(d^+(u))$
遍历整张图的时间复杂度 $O(n+m)$
空间复杂度 $O(m)$

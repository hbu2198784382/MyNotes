有向无环图（Directed Acyclic Graph,DAG）即不存在[[图论相关概念#圈|圈]]的[[图论相关概念#有向图|有向图]]。

# 拓扑排序
对于有向无环图 $G$ ，其拓扑排序是顶点的一个序列 $topo$ ，**使得对任意的 $u$ 到 $v$ 存在一条边，$u,v$ 在 $topo$ 的序列保证 $u$ 在 $v$ 之前**。
> [!NOTE] 定理
> $G$ 是有向无环图 $\Leftrightarrow$ $G$ 可以拓扑排序

## Kahn 算法
Kahn 算法用于完成 DAG 的拓扑排序。基于入度的统计完成。时间复杂度 $O(V+E)$ 。
### 算法步骤
1. 统计所有节点的入度
2. 把所有入度为 0 的节点加入队列 q
3. 队列 q 头节点 u 出队，加入 topo 序列
4. 遍历所有 u 的出边，将其所有后继节点 $v$ 的度全部减去 1，若 $v$ 的度为 0 ，则加入队列。
5. 回到 3，直到队列为空
> **若最终 topo 序列长度小于总节点数，说明存在圈**

... // build DAG (N:nodes,M:edges)

while(!q.empty()){

}

# DAG 上的 DP
使用[[递归与动态规划]]，可以找到简便的找到 $DAG$ 中从 $s$ 到 $v$ 的最短（长）路径，**而避免使用其他更复杂的图算法**。
## 思路分析
以最短路径为例，假设 $f(v)$ 表示从 $s$ 到 $v$ 的最短路径，设 $v$ 的前驱节点集为 $F$ ，则列出状态转移方程：$$f(v)=min_{u\in F}(f(u)+w_{(u,v)})$$ 特别地，对边界条件， $f(s)=0$ 。自然可以使用递归自顶向下计算最短路径，但是要进一步化简，则可以考虑使用自底向上的方法。发现：**只要按照拓扑排序的顺序进行计算，就可以实现自底向上的计算。** *因为所有节点的前驱节点一定已经计算过了。*

## 算法步骤
1. 对 $DAG$ 拓扑排序，得到序列 $topo$ 
2. 初始化 dp\[s\] = 0，其余为 $+\infty$ 
3. 按照 $topo$ 的顺序依次遍历每个节点 $u$ ，
	- 若 dp\[u\] = $+ \infty$ ，由于 $u$ 之前的所有节点都已经计算，说明不存在路径到达 $u$ ，故跳过此节点。
	- 否则，对 $u$ 的所有后继节点：dp\[v\] = min(dp\[v\],dp\[u\]+w)。
	- （可选，若要还原路径）若 dp\[v\] 发生改变，则将 parent\[v\] 改为 $u$ 。

## 实现代码
以[[图的存储#链式前向星|链式前向星]]存储的 DAG 为例。
```cpp
int head[N],to[M],nxt[M],w[M];
... // build DAG (N:nodes,M:edges)

//kahn toposort
int d[N],u,e,start,fin,t; queue<int> q;
memset(d,0,sizeof(int)*N);
for(int i = 0;i < M;i++) d[to[i]]++;
for(int i = 0;i < N;i++) if(d[i]==0) q.push(i);

int dp[N],parent[N];
for(int i = 0;i < N;i++) dp[i] = INF;
memset(parent,-1,sizeof(int)*N);
scanf("%d%d",&start,&fin);dp[start] = 0;

while(!q.empty()){
	u = q.front();q.pop();e = head[u];
	while(e!=-1){
	if(dp[u]<INF){t = dp[u]+w[e];
		if(t < dp[to[e]]) {dp[to[e]]=t;parent[to[e]]=u};
	}
	if((--d[to[e]]) == 0) q.push(to[e]);
	e=nxt[e];
	}
}

// shortest distance
printf("%d",dp[fin]);
// shortest path (reverse)
while(fin!=-1){printf("%d ",fin);fin = parent[fin];}
```

> [!NOTE] 为什么在初始化 dp 数列时不使用 memset
> 事实上，c++中的 memset 函数是逐字节进行的，也就是说，对于 32 整数 int 类型的数组 dp ，在使用 memset 初始化为 INF = `0x7fffffff` (2147482647) 时，会取其低八位 `0xff` 逐个存入连续的数组中，同时重复设定的次数。这样就会导致数组的每一项变成 `0xffffffff` 即 -1，导致程序错误。因此，**在将数组初始化为 `-128~127` 之间的数时使用 memset 函数是安全的。但是在其他情况下考虑 for 循环依次赋值。**

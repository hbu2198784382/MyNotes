# 基本概念
给定一个图，求取从 $s$ 节点出发到 $f$ 节点的所有[[图论相关概念#路径|路径]]中，使得所有边权之和最小的一条。

## 负环
即边权之和是负值的[[图论相关概念#圈|环]]。对于存在负边权的图，且不要求搜索路径，而是允许存在环。那么若存在负环，就会导致最短路径不存在，因为每绕环一次，边权之和就会越来越小。

# Floyd 算法
Floyd 算法的时间复杂度 $O(n^3)$ ，空间复杂度 $O(n^2)$ ，可以适用于任意不存在负环的图中。
参考 [[Floyd 算法]]

# Bellman-Ford 算法
Bellman Ford 算法的时间复杂度 $O(mn)$ ，空间复杂度 $O(m)$ ，可以适用于任意图中，并可以检测是否存在负环。在经过 SPFA 优化后时间复杂度进一步减小。
参考 [[Bellman-Ford 算法]]

# Dijkstra 算法
Dijkstra 算法的时间复杂度 $O((n+m)\log n)$ ，空间复杂度 $O(n+m)$ ，只能适用在非负边权图中，使用二叉堆进行优化。
参考 [[Dijkstra 算法]]

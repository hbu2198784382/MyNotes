# 核心思想
**将图的所有边权从小到达排序，从第一个边开始，只要加入当前边不会导致成环，就加入这个边，否则跳过。直到选完 $n-1$ 条边就停止选择。**

## 算法步骤
1. 所有边按照边权从小到大排序，假设所有点各自属于一个集合。
2. 从小到大遍历排序后的边，若边的两个端点 $(u,v)$ 在同一集合，说明成环，跳过；否则选择这条边，且合并 $u,v$ 所在的集合。
3. 当选择的边数到达 $n-1$ 时，停止选择。
*若遍历完整张图后的边数无法达到 $n-1$ ，说明图不连通* 。

## 并查集优化
由于算法要频繁的判断两个节点是否在同一集合中，故使用[[并查集]]来优化算法，可以将每次查找与合并的时间复杂度降低到 $O(1)$ 。

# 实现代码
分析可得算法的实际时间复杂度取决于第一步的边权排序，算法的时间复杂度就是排序的时间复杂度。由于需要频繁获取边的两个端点，故采用[[图的存储#存边|存边]]的方式，加上并查集的空间，空间复杂度 $O(n+m)$ 。

}

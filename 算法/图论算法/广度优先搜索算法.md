# 核心理念

广度优先搜索（Breadth First Search,BFS）算法的核心理念是：**一次性搜索一层，直到搜到底**
**借用[[队列]]的先进先出性质，从[[图论相关概念#图|图]]的任意一个节点开始，搜索所有的相邻节点，再搜索下一层节点，直到搜到终点**。BFS具有时间复杂度低，空间复杂度高的性质。

广度优先搜素算法使用队列的性质，与[[深度优先搜素算法#使用栈完成的dfs|深度优先搜素算法]]使用栈完成形成了呼应。

# 遍历方法

使用BFS遍历一张图的一般思路是：
1. 标记起点节点并入队列
2. 队列头出队列，存入temp
3. 寻找temp的所有相邻节点
4. 判断节点是否被标记过：
	a. 被标记过：跳过此节点
	b. 未被搜索：
		(1) 将此节点的入队列
		(2) 将此节点的父节点指向temp 
		(3) 标记此节点
5. temp的所有相邻节点搜索完成后，回到2，直到队列为空

这样一来，会形成一个以起点节点为根节点的[[树]]，**这棵树称为BFS树，从根节点到达终点的路径就是最短路径。同时，BFS树中的每一个元素都只可能出现一次（可以用于去重）**。

> [!question] 为什么BFS树的路径一定是最短路径
> 来源于队列的**先进先出性质**，在每次搜索的过程中，已经搜索过的节点不再进入队列，说明**存在一条更短的路径到达此节点**。因此在每次搜索的过程中，都排除了所有比现有路径更长的路径，从而留下的就是最短路径。

# 经典例题：迷宫最短路径

> [!NOTE] 迷宫最短路径
> 给定一个 $m$ 行，$n$ 列的迷宫，左上角起点 $(0,0)$，右下角终点 $(m-1,n-1)$，迷宫中放有 $k$ 个障碍物，现在要求输出到达终点的最短路径。（若无法到达终点输出`error`)
> 
> 输入格式：
> 共 $k+1$ 行，第 $1$ 行依次输入 $m,n,k$；第 $2$ 到 $k+1$ 行依次输入 $k$ 个障碍物的行与列。
> 
> 输出格式：
> 每行依次输出途径格子的行与列。

## 基本思路

1. 将起点加入队列。
2. 队列头弹出，存入temp。
3. 按照下右左上的顺序，搜索temp的所有相邻节点。
4. 判断：
	如果节点不可走（障碍），或者已经被标记，则跳过；
	如果搜索到终点节点，结束搜索，从终点节点回溯到根节点，依次打印；
	否则：标记此节点 -> 此节点的父节点指向temp -> 此节点入队列
5. temp的所有相邻节点搜索完毕后：
	 如果队列不为空，回到2；
	 如果队列为空，说明不存在到达终点的路径，打印error。

## 实现代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    int m,n,k;
    scanf("%d%d%d",&m,&n,&k);
    // position format: row*n+column
    int* obp = new int [n*m](); // position of obstacle
    int ro,co;
    for(int i = 0;i < k;i++){
        scanf("%d%d",&ro,&co);
        obp[ro*n+co] = 1;
    }printf("\n");
    int* fp = new int [m*n](); // postion of father node
    int* flag = new int [m*n](); // if the node is visited
    queue<int> q;
    // start bfs
    q.push(0);bool finded = false;flag[0] = 1;
    int temp;
    while(!finded && !q.empty()){
        temp = q.front();q.pop();
        // search near
        int r = temp/n, c = temp%n;
        stack<int> near;
        if(r+1 < m) near.push(temp+n);
        if(r-1 >= 0) near.push(temp-n);
        if(c+1 < n) near.push(temp+1);
        if(c-1 >= 0) near.push(temp-1);
        while(!near.empty()){
            int top = near.top();
            if(!obp[top] && !flag[top]){
                if(top == m*n-1){finded = true;fp[top]=temp;break;}
                else{
                    flag[top] = 1;
                    fp[top] = temp;
                    q.push(top);
                }}near.pop();}}
    if(!finded){printf("error");return 0;}
    stack<int> path;
    int ptr = m*n-1;
    while(ptr != 0){path.push(ptr);ptr = fp[ptr];}path.push(0);
    while(!path.empty()){printf("%d %d\n",path.top()/n,path.top()%n);path.pop();}
    return 0;
}
```

# BFS 序列

# 双端队列 BFS

使用[[双端队列]]，将 BFS 的过程进行优化，双端队列 BFS 使用于权值为 0 或 1 的情况，因此又称 0-1 BFS。

# 核心思想
Floyd 算法用于搜索两点之间的最短路，其核心思想是：**在两点之间引入一个中间节点 $k$ ，比较经过 $k$ 以后是否会出现更短路线。**

*Floyd算法可以使用在任意图上，不受到连通、是否有圈的限制。* **注意：Floyd不具备判断[[最短路问题#负环|负环]]的能力，使用时要保证图中不存在负环**

假设 $dis(x,y)$ 表示从节点 $x$ 到节点 $y$ 的最短路径，现在引入中间节点 $k$ ，可以列出状态转移方程：$$dis(x,y)=min_{k\in N}~(dis(x,k)+dis(k,y))$$
特别地，$dis(x,x)=0$，
对所有 $u$ 到 $v$ 之间存在边，$dis(u,v)=w$，否则 $dis(u,v)=+\infty$。

## 实现代码
不难看出，使用[[图的存储#邻接矩阵|邻接矩阵]]存储图进行 Floyd 算法是最佳的。
```cpp
int* dis[n*n];
for(int i=0;i<n*n;i++) dis[i]=INF; //initialize
for(int i=0;i<n;i++) dis[i*n+i]=0; // border
... // build graph

for(int k = 0;k < n;k++)
	for(int x = 0;x < n;x++)
		for(int y = 0;y < n;y++)
			if(dis[i*n+k]+dis[i*k+y] < dis[i*n+j])
			dis[i*n+j]=dis[i*n+k]+dis[i*k+y];
```

发现算法时间复杂度 $O(n^3)$
*注意：$k$ 必须要放在最外层遍历。接下来进行解释。*

## 算法合理性证明
初始时，$dis$ 中只包含直接边与自身。
当 $k=0$ 时，表示经过节点 $0$ 的最优解。
当 $k=1$ 时，增加了节点 $1$ ，表示经过节点 $0,1$ 的最优解。
当 $k=2$ 时，增加了节点 $2$ ，表示经过节点 $0,1,2$ 的最优解。
......
当 $k=n-1$ 时，增加了节点 $n-{1}$ ，表示经过节点 $0,1,2,\dots,n-1$ 的最优解，即在整张图内的最优解。

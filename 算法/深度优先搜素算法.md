# 核心理念

深度优先搜索算法（Depth First Search,DFS）的核心就是：**一次性搜到底，回溯后再次搜索。**
**利用[[递归与动态规划#递归的一般思路|递归]]的方式，从[[递归与动态规划#递归树|递归树]]的根节点开始，依次遍历所有子节点，直到搜索到根节点，在回溯搜索另一分支**

**基本要素：结束条件、递归调用、回溯状态**

# 经典例题：八皇后问题

>[!NOTE] 八皇后问题
>在国际象棋的棋盘（8x8）上摆放八个皇后（横竖斜均可吃），使得任意两个皇后无法相互吃。打印出所有解法。
## 基本思路

从第一行开始依次摆棋，摆完一行后递归摆下一行，摆完八个棋子之后进行判断局面是否合规，合规即打印。期间使用数组保存局面，便于进行回溯。（check函数用于检查局面，print打印局面，均省略）
```cpp
#include <bits/stdc++.h>
using namespace std;
int temp[8] = {-1,-1,-1,-1,-1,-1,-1,-1};

void dfs(int row){
    // border
    if(row == 8){check();print();return;}
    // dfs
    for(int i = 0;i <= 7;i++){
        temp[row] = i;
        dfs(row+1);
    }
}
int main(){
    dfs(0);
    return 0;
}
```

## 算法优化：剪枝

以上的递归搜索会产生一颗递归树，为了降低递归树的规模，我们分析得知：**在向深处递归的过程中，部分节点已经不满足条件了，其子树必然无法找到符合条件的解**，因此使用条件判断，在过程中便筛掉不符合的节点。

```cpp
#include <bits/stdc++.h>
using namespace std;
int temp[8] = {-1,-1,-1,-1,-1,-1,-1,-1};
int ans = 0;

int abs(int x){
    if (x < 0) return(-x);
    else return x;
}

bool check(int r1,int c1,int r2,int c2){
    if(r1 == r2 || c1 == c2) return false;
    else if(abs(r1-r2) == abs(c1-c2)) return false;
    else return true;
}

void dfs(int row){
    // border
    if(row == 8){
        printf("\n No.%d\n",ans+1);
        // print
        for(int i = 0;i <= 7;i++){
            for(int j = 0;j <= 7;j++){
                if(j == temp[i]) printf("Q");
                else printf("*");
            }
            printf("\n");
        }
        ans++;
        return;
    }
    // dfs
    for(int i = 0;i <= 7;i++){
        temp[row] = i;
        // check
        bool ok = true;
        for(int j = 0;j <= row-1;j++){
            if(!check(j,temp[j],row,i)){ok = false;
            break;}
        }
        if(ok) dfs(row+1);
    }
}

int main(){
    dfs(0);
    printf("total: %d\n",ans);
    return 0;
}
```

# 使用栈完成的dfs

> [!NOTE] 例题
> 给定一棵树的根节点，搜索这棵树的全部节点。

使用dfs完成时，我们常常使用递归的方法

```cpp
void dfs(TreeNode* root){
	if(root->childnum == 0) return;
	for(int i = 0;i < root->childnum;i++){
		dfs(root->children[i]);
	}
}
```

利用[[栈]]，我们可以避免递归。

```cpp
int main(){
	// get rootnode
	...
	
	// dfs
	stack<TreeNode*> st;
	st.push(rootptr);
	while(!st.empty()){
		TreeNode* top = st.pop();
		if(top -> childnum > 0){
			for(int i = 0;i < childnum;i++) st.push(top -> children[i]);	
		}	
	}
}
```

> 为什么栈能够很好的模拟递归过程？事实上，在CPU中函数的跳转就是依靠栈来实现的。参考[[转移指令#CALL 指令|8086汇编中的CALL指令]]


# 图论DFS

使用dfs搜索一张[[图论相关概念#图|图]]的过程中，需要给已经搜索过的图打上标记。

## 递归实现
1. 标记起点节点
2. 寻找起点节点的所有相邻节点
3. 判断节点是否被标记：
	a. 如果没有被标记，就将该节点的父节点指向起点节点，递归搜索该节点
	b. 如果被标记，就跳过该节点

## 栈实现
1. 标记起点节点，起点入栈
2. 栈顶出栈，存入temp
3. 寻找temp的所有相邻节点
4. 判断节点是否被标记：
	a. 被标记：跳过此节点
	b. 没有被标记：标记此节点 -> 此节点的父节点指向temp -> 此节点入栈
5. temp的所有相邻节点搜索完后，回到2，直到栈空

## DFS 序列
DFS 序列是指 DFS 调用过程中访问节点编号的序列。
每颗子树都与 DFS 序列中的一段连续子序列对应。[[图论相关概念#连通图|连通图]]的 DFS 序列通常是不唯一的。

## DFS 树
当使用 DFS 遍历一张（强） [[图论相关概念#连通图|连通图]]时，将先访问的节点作为父节点，在其之后的节点作为其子节点形成的[[树]]，称为 DSF 生成树。

### 树边
在搜索过程中，每次搜索到一个未搜索过的节点，就形成了树边。
### 回边
指向其祖先节点的非树边。
### 前向边
指向其后代节点的非树边。
### 横叉边
不属于以上三者的边。

# 二叉树上 DFS
在[[树#二叉树|二叉树]]上进行 DFS 时，有以下几种遍历顺序：
## 先序遍历
先访问根节点，再访问左节点，最后访问右节点。
```cpp
void preorder(BiTree* root) { 
	if (root) { 
		cout << root->key << " "; 
		preorder(root->left); 
		preorder(root->right); 
	}
}
```

## 中序遍历
先访问左节点，再访问根节点，最后访问右节点。
## 后序遍历
先访问左节点，再访问右节点，最后访问根节点。

# 题目内容
## 题目描述

在一个果园里，多多已经将所有的果子打了下来，而且按果子的不同种类分成了不同的堆。多多决定把所有的果子合成一堆。

每一次合并，多多可以把两堆果子合并到一起，消耗的体力等于两堆果子的重量之和。可以看出，所有的果子经过 $n-1$ 次合并之后， 就只剩下一堆了。多多在合并果子时总共消耗的体力等于每次合并所耗体力之和。

因为还要花大力气把这些果子搬回家，所以多多在合并果子时要尽可能地节省体力。假定每个果子重量都为 $1$，并且已知果子的种类数和每种果子的数目，你的任务是设计出合并的次序方案，使多多耗费的体力最少，并输出这个最小的体力耗费值。

例如有 $3$ 种果子，数目依次为 $1$，$2$，$9$。可以先将 $1$、$2$ 堆合并，新堆数目为 $3$，耗费体力为 $3$ 。接着，将新堆与原先的第三堆合并，又得到新的堆，数目为 $12$，耗费体力为 $12$。所以多多总共耗费体力 $=3+12=15$。可以证明 $15$ 为最小的体力耗费值。

## 输入格式

共两行。  

第一行是一个整数 $n(1\leq n\leq 10^4)$，表示果子的种类数。  

第二行包含 $n$ 个整数，用空格分隔，第 $i$ 个整数 $a_i(1\leq a_i\leq 2\times 10^4)$ 是第 $i$ 种果子的数目。

## 输出格式

一个整数，也就是最小的体力耗费值。输入数据保证这个值小于 $2^{31}$。

## 输入输出样例 #1

### 输入 #1

```
3 
1 2 9 

```

### 输出 #1

```
15

```

## 说明/提示

对于 $30\%$ 的数据，保证有 $n \le 10^3$；

对于 $50\%$ 的数据，保证有 $n \le 5\times10^3$；

对于全部的数据，保证有 $n \le 10^4$。

# 思路分析

## 贪心证明
先来尝试划分子问题。将任意两堆果子合并后，形成了 $n-1$ 堆果子。求解合并这 $n$ 堆果子的最小代价就等价于**找到一对 $(i,j)$ ，使得合并了第 $i,j$ 两堆果子后，这次合并的代价（$a_{i}+a_{j}$）与合并新的 $n-1$ 堆果子代价的总和最小。** 对于边界条件，在仅剩下两堆果子时的最小合并方式就是合并这两堆果子。

因此分析得到该问题具有[[贪心算法#最优子结构|最优子结构]]，考虑使用[[贪心算法]]，提出贪心策略：
> 每次都选择数量最少的两堆果子合并，直到所有的果子合并完成。

## 堆优化
因为过程中需要频繁选择最小的两堆果子，或者加入新的果子，因此使用[[二叉堆]]进行优化，降低时间复杂度。建立一个最小堆，每次合并时弹出两次堆顶，再将合并后的数据入堆。只要进行 $n-1$ 次操作即可

# 实现代码
```cpp
#include <bits/stdc++.h>
using namespace std;

void sink(int i,int n,int* heap){
    int t = i,s,l,r,sw;
    while(1){
        s = t;l = 2*t+1;r = 2*t+2;
        if(l <= n-1 && heap[l] < heap[s]) s = l;
        if(r <= n-1 && heap[r] < heap[s]) s = r;
        if(s == t) break;
        sw = heap[t];heap[t] = heap[s];heap[s] = sw;
        t = s;
    }
}

void swim(int i,int n,int* heap){
    int t=i,sw;
    while(t>0){
        if(heap[(t-1)/2] <= heap[t]) break;
        sw = heap[t];heap[t] = heap[(t-1)/2];heap[(t-1)/2] = sw;
        t = (t-1)/2;
    }
}

int main(){
    int n,x,y,sum=0;scanf("%d",&n);
    int* heap = new int [n];
    for(int i = 0;i < n;i++) scanf("%d",&heap[i]);
    for(int i = n/2-1;i >= 0;i--) sink(i,n,heap); // heapify
    while(n>1) {
        x = heap[0]; heap[0] = heap[n-1]; n--; sink(0,n,heap); // pop
        y = heap[0]; heap[0] = heap[n-1]; n--; sink(0,n,heap);
        heap[n] = (x+y); n++; swim(n-1,n,heap); // push
        sum += (x+y);
    }
    printf("%d",sum);
    delete[] heap;
    return 0;
}
```

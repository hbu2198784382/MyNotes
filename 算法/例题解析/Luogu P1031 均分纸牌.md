# 题目内容

## 题目描述

有 $N$ 堆纸牌，编号分别为 $1,2,\ldots,N$。每堆上有若干张，但纸牌总数必为 $N$ 的倍数。可以在任一堆上取若干张纸牌，然后移动。

移牌规则为：在编号为 $1$ 堆上取的纸牌，只能移到编号为 $2$ 的堆上；在编号为 $N$ 的堆上取的纸牌，只能移到编号为 $N-1$ 的堆上；其他堆上取的纸牌，可以移到相邻左边或右边的堆上。

现在要求找出一种移动方法，用最少的移动次数使每堆上纸牌数都一样多。

例如 $N=4$ 时，$4$ 堆纸牌数分别为 $9,8,17,6$。

移动 $3$ 次可达到目的：

- 从第三堆取 $4$ 张牌放到第四堆，此时每堆纸牌数分别为 $9,8,13,10$。
- 从第三堆取 $3$ 张牌放到第二堆，此时每堆纸牌数分别为 $9,11,10,10$。
- 从第二堆取 $1$ 张牌放到第一堆，此时每堆纸牌数分别为  $10,10,10,10$。

## 输入格式

第一行共一个整数 $N$，表示纸牌堆数。  
第二行共 $N$ 个整数 $A_1,A_2,\ldots,A_N$，表示每堆纸牌初始时的纸牌数。

## 输出格式

共一行，即所有堆均达到相等时的最少移动次数。

## 输入输出样例 #1

### 输入 #1

```
4
9 8 17 6

```

### 输出 #1

```
3

```

## 说明/提示

对于 $100\%$ 的数据，$1  \le  N  \le  100$，$1 \le  A_i  \le 10000$。

**【题目来源】**

NOIP 2002 提高组第一题

# 思路分析
该题可以使用[[贪心算法]]完成目标，分析得每一堆的牌数都应该是平均值 $avg=(\sum_{i=1}^{N}A_{i})/N$，现在试图找出一个贪心策略：
> 从第一堆开始，用后一堆的牌与当前堆的牌交换，如果某堆本就补齐就跳过，直到所有牌堆补齐。

记 $g_{k}$ 表示用第 $k+1$ 堆牌补齐第 $k$ 堆牌（$k<N$），若已经补齐则跳过，现在证明该策略的正确性：

## 最优子结构
假设将编号从 $a$ 到 $N$ 的牌堆都补齐为 $avg$ 为的最少操作步骤为 $S(a)$ ，则有：
当 $a=avg$ 时：（跳过本次补齐）$$S(a)=S(a+1)$$
当 $a \neq avg$ 时：$$S(a)=1+S(a+1)$$
对于边界， $S(N)=0$ 。

## 贪心性质
假设补齐第 $a$ 堆到第 $N$ 堆牌的最优解为 $OPT(a)$，即证明贪心选择 $g_{k}$ 在 $OPT(1)$ 中必然存在。若第一堆已经补齐，则 $g_{1}\in OPT(1)$ 恒成立（不移动）；若第一堆没有补齐，由于第一堆只能用第二堆补齐，则 $g_{1}\in OPT(1)$ 恒成立。由于最优子结构性质，可以得到 $OPT(2) \subset OPT(1)$ 。现在讨论 $OPT(2)$：
- 如果第二堆已经被补齐，那么 $g_{2}\in OPT(2)$ 已经成立；
- 如果第二堆没有被补齐，若是选择第二堆牌使用第一堆牌补齐，由于第一堆已经补齐，则必然需要花额外步数补齐第一堆。说明第二堆牌只能选择第三堆补齐，故 $g_{2}\in OPT(2)$。
综上，$g_{2}\in OPT(2)$ ，由于 $OPT(2) \subset OPT(1)$ ，可以得到 $g_{2} \in OPT(2)$。利用递推归纳，可以得到 $g_{k}\in OPT(1)$ 对任意的 $k<N$ 都成立。

# 解题代码
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int N,l[101],sum=0,t=0;scanf("%d",&N);
    for(int i = 0;i < N;i++){scanf("%d",&l[i]);sum+=l[i];}// avg=sum/N
    for(int i = 0;i < N-1;i++){
        if(l[i] == sum/N) continue;
        l[i+1] += (l[i]-sum/N);t++;}
    printf("%d",t);
    return 0;
}
```
